How to update Hongguo Downloader without losing your library

By M4St3r0·Updated 28 August 2026·~6 min read
Short answer

You won't lose anything. Whichever way you update — a quick Update or a full Clean Install — Hongguo Downloader always keeps your license and your entire downloaded library. The choice only affects the app's internal caches and settings, never your saved video files. Below is exactly how to update, where your library actually lives on disk, and what to check if anything looks off afterward.

Updating any app you rely on for a growing collection of files is a fair thing to be cautious about — nobody wants to reopen a downloader and find a poster wall of missing episodes. Here's the straight version of how updates work in Hongguo Downloader and why your library survives every one of them.

Why your library isn't at risk

Your downloaded episodes are plain .mp4 files saved to a folder on your own PC — the app doesn't store them inside some special container that an installer could wipe. Updating replaces the application itself (the program that searches, queues, and saves new episodes); it does not touch the folder where your finished downloads already sit. That separation is exactly why the app's own installer can offer a full Clean Install option at all — resetting the app's internal state has nothing to do with the video files you've already saved.

How to update, step by step

  1. Check for an update. Open Hongguo Downloader and go to the Account panel. The update button reads Check Update when you're on the latest version, or switches to a one-click New Version Available label when an upgrade is ready.
  2. Or grab the installer directly. You can always download the current build straight from the official GitHub release — no need to uninstall the old version first.
  3. Run the installer. You'll be asked to choose Update (refresh in place, fastest) or Clean Install (reset stale caches, start fresh). Pick either — your license and library carry over both ways.
  4. Let it finish, then reopen the app. Your poster wall, your license, and every previously saved episode should be exactly where you left them.

If you saw a Windows SmartScreen warning during this step, that's normal for a fresh installer build and not a sign anything's wrong — see the SmartScreen fix guide for exactly where to click.

In practice, Update is the right default for most people — it's quick and does exactly what you'd expect. Reach for Clean Install only if you've been having odd behavior (a stuck queue, a search that won't refresh) and want the app's own caches wiped without touching your saved episodes.

Where your library actually lives, and how it stays current

Every episode you've downloaded shows up on the app's Library poster wall, whether you updated recently or not. If a series you've already downloaded gets new episodes on 红果 after you saved it, the Library flags it with a "+N new" badge — and Update all grabs only the missing episodes rather than re-downloading anything you already have. None of that behavior changes across an update; it's the same library, the same folder, before and after.

What to check if something looks off after updating

This is rare, but if your Library ever looks emptier than expected right after an update:

  • Give the app a moment to rescan. The Library rebuilds its poster wall from the files on disk when it reopens — on a large collection this can take a few seconds.
  • Confirm you're logged into the same license. If you have a key, make sure the Account panel shows it as active — your library is tied to your local install, not a cloud account, so this is mostly a sanity check.
  • Don't run Clean Install repeatedly as a fix for something unrelated. It resets app state, not your files — if episodes are genuinely missing from disk, that's a files-on-disk issue to check directly in your downloads folder, not something an update caused.

Frequently asked questions

Will updating delete my downloaded dramas?

No. Both Update and Clean Install always keep your license and your entire downloaded library — the choice only affects the app's own caches and settings.

What's the difference between Update and Clean Install?

Update refreshes the app in place and is the fastest option. Clean Install clears stale internal caches for a fresh start. Neither one touches your saved video files.

How do I know a new version is available?

Check the Account panel — it shows Check Update when current, or a one-click New Version Available label when there's an upgrade.

Why does Windows warn me again after I update?

Each new installer build is a new file to Windows SmartScreen, so the reputation warning can reappear even on a clean update. See the SmartScreen guide for exactly where to click.
